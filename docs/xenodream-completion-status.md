# XenoDream integration completion status

The evidence-backed XenoDream development pass is complete. “Complete” here
means every roadmap item is either shipped behind an exact native contract or
stopped at a recorded failed predicate. It does not mean XenoSculpt is a
general replacement for XenoDream's editor.

The supported surface also includes hosted natural-language creation. A model
may select a verified seed and translate a request into the same bounded typed
operations used by the deterministic planner. XenoSculpt evaluates that recipe
before publication; the model has no XDX, filesystem, or native-application
write authority.

## Shipped

- Lossless XDX parsing, inspection, semantic comparison, immutable revisions,
  branches, imports, and exports.
- Verified Cube, Sphere, and Cylinder generation and measured mutations.
- Closed RoundCube, Pipe, Torus, Cog, and SpiralShell generation with scale
  and position edits.
- Exact Cube and Sphere append operations, exact empty Group3 creation, and
  two measured Cube2-in-Group3 profiles.
- Revision-bound single operations and atomic two-to-five-step controlled
  recipes with dry-run.
- Pinned XenoDream installation identity plus preview and review native
  validation profiles.
- Revision-bound mesh facts and deliberately incomplete fabrication
  assessment.

## Stopped rather than guessed

- General deletion is stopped by the retained middle-Cube result, which kept
  persistent ID 3 after section compaction and remained actively computing at
  both 10% and 1% mesh density.
- True duplication is stopped because no controlled native transition defines
  which opaque state is copied or how identity and references are allocated.
- Arbitrary reparenting, nested groups, ungrouping, and sibling reorder are
  stopped because their identity, reference, and evaluation rules are not
  established. The public Group3 operation is one closed measured family.
- Raw parameters for the five promoted constructors remain closed because
  descriptor ranges do not establish safe interactions.
- Printability remains incomplete because exact self-intersection, local
  thickness, process, support, tolerance, material, and physical-result facts
  are absent.

These are safety boundaries, not hidden TODOs. Expanding one requires a new
controlled XenoDream observation, a complete byte audit, a native evaluation,
and a packaged regression proof. Physical fabrication additionally requires a
human-selected process and a real build result.

## Final compatibility checkpoint

The final packaged executable passed the bounded Group3 workflow and native
preview. The same package also created and reopened a native MoI cylinder and
ran the model-free ComfyUI workflow against local ComfyUI 0.34.2 with the
explicit version-mismatch override. ComfyUI 0.34.2 is not promoted to the
pinned supported version by that checkpoint.

See the evidence register entries E104–E116 and the retained runtime JSON in
`evidence/runtime` for exact revision, artifact, executable, and output hashes.
